# SyncSetup

Gestionnaire d'applications pour Windows · Windows app manager

 

Français · English

# 🇫🇷 Français
SyncSetup installe, met à jour, répare et désinstalle vos logiciels depuis une seule interface, sauvegarde vos navigateurs, applications et jeux, et vous permet de tout retrouver sur un autre PC.

Télécharger
Ouvrez la dernière version.
Téléchargez SyncSetup-Setup-x.y.z.exe et lancez-le.
C'est tout : SyncSetup se met ensuite à jour tout seul.
Windows peut afficher « Windows a protégé votre ordinateur » (installateur non signé) : cliquez sur Informations complémentaires, puis Exécuter quand même.

Fonctionnalités
Catalogue de plus de 260 logiciels, installés depuis les sources officielles (winget, ou Microsoft Store au choix)
Mises à jour des logiciels et des paquets (winget, Scoop, Chocolatey, pip, npm…) au même endroit, en un clic
Profils : votre liste de logiciels, réinstallée en un clic sur un nouveau PC
Sauvegardes de plus de 50 navigateurs, applications et jeux (favoris, réglages, extensions, Discord et ses mods, mondes Minecraft…), restauration vérifiée — jamais de mot de passe ni de session de connexion
Exporter / importer toutes les données de SyncSetup dans un seul fichier
Sauvegarde GitHub de votre liste de logiciels dans un Gist secret
Optimisation du PC, matériel et pilotes, maintenance planifiée, notifications
Français ou anglais, 16 thèmes
Configuration requise : Windows 10 ou 11 (64 bits).

# 🇬🇧 English
SyncSetup installs, updates, repairs and uninstalls your software from a single interface, backs up your browsers, apps and games, and lets you get everything back on another PC.

Download
Open the latest release.
Download SyncSetup-Setup-x.y.z.exe and run it.
That's it: SyncSetup then updates itself.
Windows may show “Windows protected your PC” (unsigned installer): click More info, then Run anyway.

Features
Catalog of more than 260 apps, installed from official sources (winget, or the Microsoft Store if you prefer)
Updates for your software and packages (winget, Scoop, Chocolatey, pip, npm…) in one place, in one click
Profiles: your list of software, reinstalled in one click on a new PC
Backups of more than 50 browsers, apps and games (bookmarks, settings, extensions, Discord and its mods, Minecraft worlds…), verified restore — never any password or sign-in session
Export / import all SyncSetup data in a single file
GitHub backup of your software list in a secret Gist
PC optimization, hardware and drivers, scheduled maintenance, notifications
French or English, 16 themes
Requirements: Windows 10 or 11 (64-bit).
